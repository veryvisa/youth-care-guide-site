被扣留的人可以找谁说明权利；复核听证怎样申请、多快开；还能不能去法院。
先看结论
  1. 被扣留的病人有一整套权利。书面加口头的权利通知（Form 13.1）、独立权利顾问、二次意见、免费的复核听证（14 或 28 天内，可申请 MHLP 免费代理和免费口译），以及向法院申请。指南一页摘要
  2. 只判断病人是否仍符合 s.22(3)(a)(ii) 和 (c)，不审治疗是否适当指南 3.10
  3. 听证期限从办公室收到起算，因此直接递交或请医院当日转交，时间上更确定指南 3.10

现在就有危险：911；9-8-8（电话或短信）；Kids Help Phone 1-800-668-6868；怀疑孩子受虐待或忽视：1-800-663-9122（24 小时）。
